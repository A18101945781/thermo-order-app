# 采购单导出 · 使用说明

> 热力学餐厅订货管理小程序
> 更新日期：2026-10-11（新增「带供应商配色的 Excel」直接落盘）

---

## ⭐ 一、日常最快用法（电脑端 · 点导出即出带色表格）

已配好**自动落盘服务**：点导出后，一个**已按供应商上好色**的 `.xlsx` 直接出现在
`桌面 → 小程序订货` 文件夹，打开即用，不用再去 Console 复制粘贴、也不用粘到 WPS 再手动上色。

### 一次性设置（只做一次，做完永久生效）

微信开发者工具 → 右上角【详情】→【本地设置】→ 勾选：

> ☑ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

不勾这个，小程序不允许连本地服务，会自动降级回 CSV 模式。

### 每次使用（3 步）

1. **双击** `D:\ai\thermo-order-app\tools\start-export-server.bat`

   弹出黑色命令行窗口，显示：

   ```
   ┌───────────────────────────────────────────┐
   │   采购单自动落盘服务  已启动               │
   └───────────────────────────────────────────┘
      监听地址 : http://127.0.0.1:7788
      保存目录 : D:\UserData\Desktop\小程序订货
      接口     : POST /xlsx  生成带供应商配色的 Excel（首选）
                 POST /save  纯文本 CSV 落盘（降级）
   ```

   **这个窗口别关**，关了就停止服务。

2. 小程序 →【订货计算】→ 输入套餐份数 → 下滑到【采购汇总】→ 点【📤 导出采购单】或底部【导出全部采购单】

3. 弹窗提示「已保存到桌面」+「✅ 带色表格已存到…」→ **资源管理器自动弹出并定位到该文件**，直接拖进微信发给供应商

### 生成的 Excel 长什么样

一个文件 3 个 Sheet：

| Sheet | 内容 |
| --- | --- |
| **采购单** | 每 8 列：`序号｜原料名称｜建议采购量｜总用量｜备注｜当前库存｜单价｜预估金额`；按供应商分片，**片头标题条用该家固定色**；每家一个小计，最后整单总金额 |
| **菜单汇总** | 先散点、后预定；含每单套餐 / 订购 / 赠送 / 实际出餐菜单 / 换菜 / 加菜 |
| **口径与说明** | 每个数字的口径出处（理论用量、建议采购量、库存口径、未纳入项…） |

**供应商配色（固定，看色辨家）**：

| 供应商 | 底色 | 说明 |
| --- | --- | --- |
| 好生活 | 浅蓝 `#DEEAF6` | 字 `#1F4E79` |
| 松食配送 | 浅绿 `#E2EFDA` | 字 `#375623` |
| 赛大厨 | 浅杏 `#FCE4D6` | 字 `#833C0C` |
| 其他 | 浅灰 `#F2F2F2` | 字 `#595959`（未列入的不猜，一律灰） |

> ⚠️ **「📋 复制全文」和真机分享出来的仍然是 CSV/表格文本，带不了颜色**——
> 纯文本剪贴板和 CSV 格式本身存不下颜色。要颜色就走「导出」出 `.xlsx`。

### 特性

| 项 | 说明 |
| --- | --- |
| 保存目录 | **真实桌面** `\小程序订货`（自动创建，不存在也不报错） |
| 文件命名 | `采购单_预定备货_全部_20261011.xlsx`（后缀 `.csv` 会被自动换成 `.xlsx`） |
| 重名处理 | 不覆盖，自动加序号 `采购单_xxx(2).xlsx` |
| 服务没开 | 自动降级到原来的 CSV 落盘 / Console 打印，不报错、不丢数据 |
| 空单保护 | 没有任何采购分组时直接拒绝，不留空文件 |
| 安全性 | 只监听 `127.0.0.1` 本机回环，外网访问不到 |
| 导出后 | 自动弹出资源管理器并**定位到该文件**，无需手动打开文件夹 |

### 🔌 开机自启（免手动双击）

已在系统「启动」文件夹放入 `autostart.bat`，**每次登录 Windows 自动启动服务**（黑窗口照常弹出），不用再手动双击。

- 启动文件夹位置：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- 想关闭自启：删掉该文件夹里的 `autostart.bat` 即可
- 项目里也保留了一份 `tools\autostart.bat`，可随时重新复制过去
- 手动立即启动（不重启）：直接双击 `tools\start-export-server.bat`

> 注意：若以后移动了项目目录，需打开 `autostart.bat`（和 `start-export-server.bat`）把里面的 `D:\ai\thermo-order-app\...` 路径改成新位置，再重新放进启动文件夹。

> ⚠️ 实现说明：早期版本用过 `schtasks` 计划任务自动启动，但 Task Scheduler 拉起的 Node 进程会出现 **HTTP 不回响应**的怪象（TCP 能连上、却 0 字节返回），故改用更可靠的「启动文件夹」方式（与手动双击等价）。

### 🔴 保存目录是怎么定的（2026-10-11 重要修复）

这台机器的「桌面」被重定向到了 `D:\UserData\Desktop`，而
`C:\Users\Administrator\Desktop` 是**旧位置留下的空壳目录，它依然存在**。

老版本按 `os.homedir()\Desktop` 拼路径 ⇒ 文件全写进那个空壳里 ⇒
**用户点导出后桌面上什么都没出现**（看着像导出失败）。

现在按下面的顺序定目录，取第一个「父级桌面目录存在」的：

1. 环境变量 `EXPORT_DIR`（手动指定，最高优先）
2. `tools\export-server.config.json` 里的 `outDir`（想固定就写这个文件）
3. **系统真实桌面**（先问 `reg.exe`，被安全策略挡住就问 PowerShell 的 `[Environment]::GetFolderPath('Desktop')`）
4. `%USERPROFILE%\Desktop`
5. `%USERPROFILE%\OneDrive\Desktop`

黑窗口里那句「保存目录」就是最终生效路径，拿不准就以它为准。

## 二、真机导出（发给供应商最直接）

手机上连不到电脑的 `127.0.0.1`，所以手机端**只能走 CSV + 微信原生分享**（没有颜色）。

1. 开发者工具顶部【预览】→ 手机微信扫码打开（或直接开体验版）
2. 【订货计算】→ 输入份数 → 【采购汇总】→ 点导出
3. **微信弹出原生分享面板** → 选文件传输助手 / 供应商微信 / 供应商群
4. 对方直接收到 csv 文件

> 想要带色表格：把同一份采购单在**电脑上**再导出一次即可。

## 三、降级方案：Console 复制（服务没开时）

1. 点导出 → 提示"文件已生成"
2. 开发者工具右侧【调试器】→【Console】
3. 找到这段：

   ```
   ========== 导出文件 采购单_xxx_20260731.csv ==========
   原料名称,单位,采购量,单价,金额
   大米,kg,12.80,5.40,69.12
   ========== END (xxx chars) ==========
   ```

4. 选中两条 `=====` 之间内容 → 复制 → 记事本粘贴 → 另存为 `.csv`，编码选 **UTF-8**

## 四、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 弹窗说"文件已生成"而不是"已保存到桌面" | 服务没启动，或没勾"不校验合法域名" | 双击 bat 启动服务；去本地设置勾选 |
| 黑窗口提示"端口 7788 已被占用" | 服务已经在跑了 | 关掉旧窗口再启动，或直接用现在这个 |
| 双击 bat 一闪而过 | Node 路径变了 | 打开 bat 检查 `NODE_EXE` 路径是否存在 |
| 桌面文件夹里没文件 | **桌面被重定向 / 服务写到了空壳桌面** | 看黑窗口里那句「保存目录」，去那个真实路径找 |
| 导出成功但表格**没有颜色** | 服务没开，走了 CSV 降级 | 启动服务后再导出一次；复制全文永远是纯文本，没颜色是正常的 |
| Excel 打开乱码 | 用记事本另存时选了 ANSI | 另存时编码选 UTF-8 |
| 生成很慢（1~2 秒） | 首次要拉起 Python + openpyxl | 正常，第二次就快了 |
| 大米还显示"松食配" | 本地缓存旧数据 | 小程序【我的】→清除缓存→重启 |
| 想关掉开机自启 | 不需要登录就起服务 | 删除「启动」文件夹里的 `autostart.bat` |

### 想换保存目录？

两种办法，任选一种：

```bat
rem 办法 A：启动前设环境变量（写在 bat 里 "%NODE_EXE%" 那行之前）
set EXPORT_DIR=D:\采购单
```

```json
// 办法 B：建一个 tools\export-server.config.json（一劳永逸）
{ "outDir": "D:\\采购单" }
```

## 五、技术实现（备查）

| 部分 | 文件 |
| --- | --- |
| 本地落盘服务 | `tools/export-server.js`（Node http，端口 7788，含 `/xlsx` 与 `/save`） |
| 启动脚本 | `tools/start-export-server.bat` |
| 带色表格渲染 | `D:\ai\_gen_purchase_xlsx.py`（Python + openpyxl） |
| 表格配色/样式库 | `D:\ai\_xlsx_style.py`（`SUPPLIER_COLORS` / `supplier_color()`） |
| 小程序端请求 | `miniprogram/utils/excel.js` → `trySaveXlsxToDesktop()` / `trySaveToDesktop()` |
| 保存主逻辑 | `miniprogram/utils/excel.js` → `savePurchase()` / `saveCSV()` |
| 结果分发 | `miniprogram/utils/excel.js` → `shareFile()` |
| 导出入口 | `miniprogram/pages/orderCalc/orderCalc.js` → `onExportSupplier()` / `onExportAll()` / `_openPreview()` |
| 回归探针 | `D:\ai\_probe_export_server.js`（26 项，含 openpyxl 反读验色） |

**决策链路**：

```
savePurchase()                       ← PC 与真机共用入口
  ├─ 真机 (ios/android) ──→ saveCSV() ──→ 写沙箱 ──→ wx.shareFileMessage 分享面板（CSV，无色）
  └─ PC (devtools/windows/mac)
       ├─ POST 127.0.0.1:7788/xlsx 成功 ──→ 带色 .xlsx 落桌面 ──→ 弹窗"已保存到桌面"＋绿色提示条
       └─ 失败/超时 20s ──→ 退回 saveCSV()
                             ├─ POST 127.0.0.1:7788/save 成功 ──→ CSV 落桌面
                             └─ 失败/超时 3s ──→ Console 打印 CSV ──→ 写沙箱 ──→ 复制路径弹窗
```

服务端接口：

| 接口 | 入参 | 出参 |
| --- | --- | --- |
| `GET /ping` | — | `{ok, dir, xlsx, gen, python}`（`xlsx:false` 表示生成脚本缺失） |
| `POST /xlsx` | `{fileName, payload}`，`payload` 与 `buildFullCsv()` 入参同构 | `{ok:true, kind:"xlsx", path, fileName}` |
| `POST /save` | `{fileName, content}` | `{ok:true, kind:"csv", path, fileName}` |

- 文件名做了安全过滤（去除 `\ / : * ? " < > |` 与前导点），防目录穿越
- `/save` 只收 `.csv`、`/xlsx` 只收 `.xlsx`，互相串不了台
- `EXPORT_NO_OPEN=1` 可关掉「自动弹资源管理器」（自检/自动化用）
- 调 Python 用受管 venv：`…\python\envs\default\Scripts\python.exe`（managed python 不带 openpyxl）
